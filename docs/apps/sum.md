# Tiko Sum

## Job

A calm child-facing math-communication app. The child types (or follows) a formula, hears every number and symbol spoken aloud, and answers by choosing from options — never by being told the result. Math becomes another way to practise making and expressing choices.

## Product boundary

Sum is not a calculator and never behaves like one: it does not display computed results. The answer is always a **choice** the child makes (by tapping a tile or saying the number). It is also not Sequence (ordering logic) and not Say (word practice) — Sum owns numbers, operators, and quantities.

## Tiko harness

Sum is a Tiko app and uses the same harness as every other Tiko app. No exclusions.

- `TikoAppShell` from `packages/tikokit-ios`: header, settings sheet (with the shared language and colour-mode pickers), account surface, Parent Mode / Child Mode with PIN gate.
- `TikoIdentity` device-first bootstrap: opens without login on a Temporary Account.
- The shared account/mode model from [`docs/flows/shared/user-modes.md`](../flows/shared/user-modes.md).
- `TikoI18n` for all text; the Tiko voice service (Atlas, disk-cached per utterance, synthesizer fallback) for all spoken output — the same engine Say uses.
- The shared celebration engine (randomized variants, card dances, layered chimes, soft retry tone, Reduce Motion path) introduced in Say.
- A `.sum` case in `TikoAppColor` (suggested `#22c55e`, green) registered in `tools/generate-app-configs.mjs`.

## Core child flow

### Free play

1. Open without login.
2. A large friendly keypad: digits 0–9, plus, minus, equals, delete.
3. Every key press is spoken instantly in the app language: “three… plus… five…”.
4. Tapping equals speaks the whole formula once (“three plus five equals…”) and presents **three answer tiles**.
5. The child answers by tapping a tile — or, when voice answering is enabled, by saying the number.
6. The right answer triggers the celebration engine and clears for the next formula.
7. A wrong pick gets one soft acknowledgement tone, the formula is spoken again, and one wrong tile fades away. The child is never told “wrong” and never shown the result unchosen.

### Paths (gamified rows)

1. Choose a path: a themed run of five predefined formulas (like a Say session).
2. Each formula is presented and spoken automatically; the child only answers.
3. Every correct answer celebrates; finishing a path triggers the big end-of-session celebration.
4. Skip is always available; a skipped formula just goes to the next.

Paths ship in a gentle difficulty ladder and are fully editable:

- **Counting** — “1 + 1”, “2 + 1” … (answers ≤ 5)
- **Add to 10**
- **Add to 20**
- **Take away** — subtraction within 10
- **Tens** — 10 + 10, 20 + 10 …

There are no points, streaks, timers, or leaderboards — the Tiko promise. Progress is the celebration itself and a calm per-path “completed” mark that resets whenever the child replays.

## Answer tiles

- Always three options; exactly one correct.
- Distractors are *plausible*, generated by rules: ±1, ±10, digit swap, the other operand, or the result of the sibling operation (3+5 → 2 as “3−5-ish” is never shown negative; fall back to ±2).
- Distractors never repeat the correct value and never go below zero in MVP.
- Tiles are spoken when tapped-and-held (audio preview without committing), supporting choice-making the AAC way.

## Voice answering (optional)

- Off by default; a parent switches it on in settings. Only then are microphone and speech-recognition permissions requested — with the same parent-facing explanation flow as Say.
- Uses Say’s recognition engine: conservative matcher, digits accepted (“8” or “eight” in every supported language), on-device preferred, nothing recorded.
- Tapping always keeps working; voice is an addition, never a requirement.

## Everything speaks

- Digits, operators, and equals are spoken per key press with the Tiko voices, cached per utterance so the whole keypad works offline after first use.
- Number words 0–20 and the operator words are localised for en, nl, fr, es, de, mt (Say already ships 1–10).
- Parent Mode can edit how each symbol is spoken per language (“plus” vs “and”, “is” vs “equals”) — the family’s everything-is-editable rule.

## Parent Mode

- Author, edit, hide, reorder **paths**: name, emoji/image, ordered list of formulas.
- Edit the built-in paths (they are defaults, not fixed content) and reset them per language.
- Constrain free play: allowed operators, maximum number (10 / 20 / 100).
- Toggle voice answering.
- All editing uses the shared Tiko popup sheets and is per account, Child Mode never sees it.

## Interaction principles

- Never a red cross, buzzer, or spoken “wrong”; a miss is one soft tone and a calmer, smaller choice.
- Never trapped: Skip always visible, replay (re-speak formula) always available as an icon-only round button.
- Minimal text; the formula and tiles are the interface.
- The loop is quick: type or hear → choose → celebrate → next.

## Privacy

- No microphone unless a parent enables voice answering; never any stored or uploaded audio.
- No answer analytics, no accuracy tracking, no child identity required.

## Accessibility

- Large keys and tiles (min 64pt), portrait and landscape, iPad-first.
- Every control spoken and VoiceOver-labelled; Dynamic Type on parent-facing screens.
- Reduce Motion honoured by the shared celebration engine.
- No colour-only state communication (correct/incorrect is never colour-coded — there is no “incorrect state” shown at all).

## MVP non-goals

- Multiplication and division (behind a follow-up, the model supports them)
- Written answer entry
- Progress reports or mastery tracking
- Web or Android
- Negative numbers, decimals, fractions

## Definition of done

- Opens without login inside the shared harness; Parent/Child Mode per contract.
- Free play: keypad speaks every press in the active language; equals produces three tiles; correct celebrates; miss = soft tone + re-speak + one tile fades.
- Paths: five default paths, playable end-to-end with per-answer and end-of-path celebrations; Skip always works.
- Parent Mode: paths and symbol pronunciations editable per language, free-play constraints, voice-answer toggle; edits survive relaunch and are account-scoped.
- Voice answering (when enabled) accepts spoken digits/number words via the shared recognizer and never blocks tapping.
- Fully offline after first use (voice cache); no permissions requested unless voice answering is enabled.
- Unit tests: distractor rules, formula speech composition, path store overrides, answer matching.
- Works on a physical iPad.
